# 高微学习网站：Codex开发交接包

这是一套开发输入与设计说明，不是已经制作完成的网站。

## 今天的用法
1. 解压到一个新的本机项目文件夹，例如 micro-learning；不要解压覆盖拓扑网站项目。
2. 在Codex里打开这个新文件夹。六份原PDF已经在 sources/raw/，不需要再次整理/逐题截图。
3. 能找到拓扑网站的源项目时，复制一份到 reference/topology/ 或告知Codex只读路径；没有也能先按既定规则实施。
4. 把根目录 CODEX_PROMPT.md 的全文粘贴给Codex；也可以发下面的启动语：

“请按当前项目的 CODEX_PROMPT.md 直接实施。先遵守 AGENTS.md 的长期约束，读取设计与课程蓝图；先交付完整第一讲和可用主线，再按计划继续五讲。原资料已放入 sources/。不要只做首页或目录；不要修改拓扑源项目和真实学习记录。”

## 包里有什么
- CODEX_PROMPT.md：可直接复制的完整启动提示词。
- AGENTS.md：固定不应漂移的学习与数据规则。
- docs/DESIGN.md：页面、教学、证明训练、复习、导航、存储、验收。
- docs/COURSE_MAP.md：五讲全部182页的主题覆盖与数学前置定位；主题不是已编写微课。
- docs/EXERCISE_INDEX.md：17道原题的位置，包括4道In text和5.C.9跨页题。
- docs/SOURCE_AUDIT.md：文本层缺失、扫描公式、来源条件/符号疑点及处理原则。
- docs/TEACHING_SAMPLE.md：用真实课件知识点展示要求的讲解与证明细度。
- data/：机器可读课程蓝图、PPT覆盖索引、原题索引与默认配置。
- sources/raw/：你本次提供的六份原PDF，未改写。
- sources/excerpts/：相关教材章节、数学附录M.A–M.L和原题页合集，均原样抽取，页码换算见manifest。
