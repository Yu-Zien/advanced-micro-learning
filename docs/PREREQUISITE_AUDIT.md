# 前置教学补齐审计

内容版本：`2026.09.28-prereq-2`。本文件记录教学链，不把数量或自动测试当作学习效果证明。逐项机器可核对的位置与练习 ID 在 `data/prerequisite-map.json`。

## 一个具体的修改前后对照

修改前，L01 的关键句是：“理性偏好的无差异关系是等价关系，因此把 X 分成无差异类。”这句话同时跳过了三个对象层级、一个构造和两段证明。读者即使背过“自反、对称、传递”，也无法回答 `[x]` 收集什么、为什么代表元可以更换、为什么这些集合既不重叠又覆盖 X。

修改后，L01-M09 先用五张卡片区分 `a`（元素）、`{a,b}`（一个类/子集）和 `{{a,b},{c,d},{e}}`（全部组组成的集合），再把关系写成“哪些有序对被规则判为同类”。随后：

1. 分别用任意 `x,y,z` 说明自反、对称、传递在检查什么，并用“距离不超过1”展示只有自反、对称仍会失败。
2. 固定 `x` 构造 `[x]_R={y∈X:yRx}`，实际算出 `[a]=[b]={a,b}`，解释不同代表元为何给出同一个集合。
3. 展开“覆盖”以及“相交即相等”的证明；后者从公共元素 `z` 出发，对任意 `y∈[x]` 用对称与传递推出 `y∈[w]`，再交换角色取得反向包含。
4. 把同一套三性质逐项用于理性弱偏好：完备性给 `x⪰x`；无差异定义直接给对称；传递性分别串起两个方向的弱偏好。
5. 最后才进入效用：相等数值保存无差异分组，数值高低还必须保存不同组间的弱偏好顺序；“同一分划但倒置组间顺序”的反例排除只会分组的错误理解。

这不是把一句话换成更多术语，而是补齐“具体对象 → 判断规则 → 反例 → 构造 → 证明 → 经济学使用 → 练习”的完整链。

## 第12页原像补桥

L01-M13 在原像第一次实际承担论证任务时重新解释：`u⁻¹({3})` 是所有被 `u` 映到3的输入组成的集合，不是 `1/u(3)`，也不要求 `u` 存在反函数。只让 `a∈u(X)`，所以 `u⁻¹({a})` 必非空；例如4不在像集中时，`u⁻¹({4})=∅`，空集不作为分划的一块。随后以双包含证明 `u⁻¹({u(x)})=[x]_∼`。

## 进度与迁移

所有原地深化位置的稳定 lesson ID 不变。旧完成记录不会被清空，也不会被改写成“已掌握新增内容”；升级时把曾经完成、这次又新增实质教学块的模块加入 `revisitLessonIds`。L01-M09、L01-M13 另外记录到具体新 block 的映射，其余位置按 `inPlaceRevisionMapping` 映射到 `src/prerequisite-blocks.js` 中同 lessonId 的全部新 block。用户完成补学后清除相应待补标记，原主线位置和 FSRS 记录保持不动。普通新增练习只记录普通自评，不自动生成或成功评分 FSRS 卡片。

## 尚不能由自动检查证明的事

自动检查能证明内容存在、引用位置一致、状态迁移不破坏记录；它不能证明某位学习者已经理解。L01 两个关键页面已做真实浏览器教学顺序检查，其余位置完成了源码层逐项检查。后续最有价值的验收是让学习者在不看答案时解释一个类、证明相交类相等，并指出原像为何不是反函数；如果解释失败，应修订对应 block，而不是增加统计数字。
