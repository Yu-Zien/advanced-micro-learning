## 特别容易定位错误的原题

- 3.D.1：正文印刷56页 / 原PDF80，不是章末的“In text”两个词；其Cobb–Douglas例子的开始在原PDF79。
- 3.E.1：正文印刷61页 / 原PDF85，包含EMP一阶条件公式。
- 5.C.2：正文印刷138页 / 原PDF162，题目是利润函数凸性，不能误拿公式(5.C.2)当题目。
- 5.D.1：正文印刷144页 / 原PDF168，题目是有效规模的AC/MC关系，不能误拿公式(5.D.1)当题目。
- 5.C.9：原PDF185页末给公共题干，186页首给三个生产函数。后一页不是新题开头；两页必须一起读。
