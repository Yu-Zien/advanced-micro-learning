# 设计说明：一条能每天学一小时的高微主线

## 1. 用户与目标
用户正在学高级微观，当前课堂难以跟上；作业下周交，每天给高微约60分钟。四个痛点是遗忘前置、缺少具体例子与练习、证明跳步、数学概念抽象。网站目标是逐步理解并练到教材原题，不是背17个答案，也不承诺7小时掌握全部五讲。

范围以五份 PPT 为主，MWG 相关正文和数学附录提供完整定义、条件、证明与练习。目标最终覆盖五讲；开发先交付能使用的一段，再逐讲扩充，不以尚未编写的占位冒充全课程。

## 2. 保留拓扑站的结构，不再造管理系统
顶部主要入口只保留：继续学习、教材习题、目录与进度。来源/备份/设置位于折叠的辅助区域。

学习页是居中的阅读列，默认中文正文18–20px，适当行距与留白，支持字号调整。数学符号与正文一样清楚；长公式局部横向滚动，不导致整页横向拖动。桌面、iPad、手机均能读。风格贴近一本可交互教材，不用仪表盘、排行、强制倒计时、XP竞争、花哨卡片墙或三维装饰。

同一微模块连续包含：
- 这一点解决什么问题，与前后内容如何相接；
- 必要的旧知识就地简短唤醒；确有新数学前置时给最小可用解释，不塞一串未学术语；
- 一个具体例子或图，再接准确的定义/命题与符号解释；
- A 示范：完整理由；B 练习：相近但非机械照抄，答案与提示可就地展开；
- 适合此处的教材原题/小问；不适合硬塞的原题在本主题稍后的完整练习块出现；
- 本知识点学完，继续。

常规正文、A示范不需要逐句点击才能读。只有解答、额外解释/前置详细说明可折叠。普通题自评不触发完成和导航；允许纸笔、口头或心算，不要求在网页提交 LaTeX、照片或长证明。

## 3. 内容粒度：一个微模块只增加一个主要学习动作
蓝图中的主题不是微模块。例如第一讲第3页列了七种关系性质，不能直接作为一个“知识点”；可逐项理解，再做必要对照。一个长证明要有父级总路线，下设多个“这一步要完成什么”的小段，但保留整篇证明可连续回看的入口，不能把上下文割裂成碎片。

时间标签是粗估，不是截止线。默认新概念约5–12分钟可形成一个小学习动作；长证明与原题可更长，用户随时暂停并准确续读。不要为了凑时长/题数删推理，也不要为每行代数增设一道强制题。

## 4. 教学质量
概念：具体对象 → 定义 → 符号对应 → 反例或相近概念对照 → A/B。抽象数学先一维/二维，有必要才三维，最后一般 L 维；不是每一个概念机械安排四个维度。

证明：先说明已知、目标与证明路线，再逐行给出“数学步骤/这一步为什么成立/用了哪个假设”。保留量词、定义域、内点/边界、存在/唯一性等条件。最终提供一份连贯的完整参考证明；补步骤、指出假设的练习是台阶，不是完整证明的替代物。

计算：先具体两商品或单投入例子，写清待选择变量、固定参数和导数维度，再接一般式。

图示：优先复用、解释课件实际图。自绘图明确标记为教学重绘/自编例子；标注坐标、固定参数、消费集/生产集和适用条件。预算线、凸组合、无差异曲线、成本曲线可以提供小范围确定性互动，但不能先做大规模图形引擎。静态图加清楚文字也可，不依赖生图生成公式。

## 5. 教材题
五讲共列17道大题，实际题干位置见 EXERCISE_INDEX，包含4道 In text 与一道跨页题。保留原编号、英文题干、全部公共条件/小问与中文说明。命题引用题要同步提供被引用命题，而不是要求用户另翻。

A/B是自编练习，不是MWG的A/B难度级别。两者标签区分，例如“示范A/练习B”和“教材难度A（如原文标明）”。别让字母含义混淆。

原题在学习主线中自动安排，不能只躺在独立题库里。长题可分小问教学，但公共题干只维护一份，同一题所有小问可同时回看，原题总体不因只做一小问而标成完整练习完毕。

教材习题页为查找与回看辅助入口，读取与主线同一份内容和状态，不形成第二套做题/通关系统。页面浏览不产生作答记录。未确定的本周提交范围用 assignedExerciseIds=null，不把17题全部硬标为下周必交；无须因此阻塞课程开发。

提供渐进提示、教学参考解与“原题检验什么”的说明。不提供所谓自动可靠判分的长证明框；客观数值/集合选择题可用确定性检查，证明以自评和要点对照为主。自编参考解不能标“教材官方答案”。

## 6. 学习、练习、记忆三类状态分离
1. 学习流程：未开始、学习中、已完成本轮。模块末尾按钮确认本轮学习；安排的必做题实际呈现在当前流程，不允许普通“继续”直接略过一个未曾展示的必做块。无需逐题点击“确认”、无需回答正确、无需强制自评。
2. 练习自评：会做/还不会/未评价，表示看答案之前的实际表现，可记录提示使用。没有自评就是未评价，不由完成按钮填成会做。
3. FSRS：仅为精选回忆项保存排程与真实评分日志；阅读定义、展开答案、浏览课件和完成模块都不是成功回忆。初次启用与成功评分分开。

复习只在模块边界出现在同一主学习页，可设每天约10分钟的软预算；不在长证明中途弹出。先展示问题，尝试后展开，再对这一次实际回忆评分。整道长证明不要强行压成短卡；可以复习其路线或一个关键假设。还不会的普通题进入后续再练候选，不立即循环弹回。课程学完后“继续学习”仍能带出到期回顾；无到期项时如实说明，不返回空白或死循环。

## 7. 导航与存储
分别保存真正主线位置、临时浏览位置、当前回顾位置，以及滚动位置和details展开状态。
“上一知识点/下一知识点”在回看模式只浏览；“回到正在学习”恢复主线。目录默认展开并定位当前讲/主题，支持标题、术语、题号检索；以后模块可只读预览，不把中间内容批量标完成。

新项目采用独立 courseId 与数据库命名空间，不复用 topology-learning-v1。不复制真实拓扑进度或FSRS卡片。更新高微课程时保留已有ID，新增微模块使用不冲突ID，附版本迁移；不要用删库掩盖升级问题。

自动保存，支持可验证JSON导出/导入；备份包含courseId、schemaVersion、contentVersion、时间戳与有效性检查。错误课程备份拒绝导入并解释；导入前保留当前备份；读取失败不能静默清空重建。浏览离开前确保延迟写入已完成，不用整库快照覆盖恢复“回看”。

## 8. 实现取向
优先复用已提供拓扑源项目的渲染、状态、备份、回看、调度能力，保留它实际的技术栈。先查README与构建入口，发布产物不等于开发源代码。参考项目只读；如没有参考源项目，按此行为契约做最小静态实现，不假装已阅读其源码。

课件在开发时编写/审核并静态发布，用户学下一课不调用在线大模型。首版不需要API密钥、登录、云数据库、语义检索/RAG、实时AI批改或录音转写服务。可用本地静态服务运行，不以 file:// 下不可靠的资源加载方式代替正常运行验证。

数据与界面分离：课程顺序/内容、原题、数学前置、精选回顾、来源定位均有稳定ID；状态只引用ID。不要为了追求架构引入多层微服务。题干以一份结构化内容为准，多处引用。

## 9. 验收
代码检查与数学审核分别记录。至少实际验证：首次进入；连续学两模块；A/B答案和自评不跳页；原题按安排出现；还不会可继续；回看后准确回到原位置；刷新保存；备份恢复与错误课程拒绝；到期回顾只触发一次；双击继续不重复完成；最后一课之后仍能回顾；新增内容不覆盖旧进度；窄屏公式与图清晰。

内容逐主题审核：原题题干完整、引用命题齐、符号/假设正确、推导无跳步、正反例有效、图与公式一致、来源疑点可见。数值试验能找错但不能代替一般证明。不会的题不因看解答而变会做；未审核课件不得显示“已核验”。

先交付完整第一讲及四题，随后依次完成第二至第五讲；每一批都保持可运行。全量目标是182页PPT内容有去向且17题完整接入，不是把每页做一张内容稀薄的卡片。只有确实提供并审核的内容才能标为可学；planned/draft/needs_review与ready分开统计。
